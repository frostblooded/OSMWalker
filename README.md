# OSM Walker

A game about a little character on real OpenStreetMap streets, being rebuilt
from scratch in Rust as a local app.

```sh
cargo run    # play
cargo test   # test
```

The earlier TypeScript web version (playable until 2026-11-24 on GitHub
Pages) is documented in [docs/legacy/](docs/legacy/README.md), with
screenshots of every screen; its code is in git history at commit `a87edab`.
